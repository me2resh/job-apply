# Surface brief: docs/index.html

Scope: the Job Apply project page on GitHub Pages. One page. Mode: Persuade (an open-source tool's project page).

Audience: senior engineers, engineering managers, product and design leads who already use a coding agent and distrust AI-written applications. Job: understand the add-on in one screen, trust that it will not lie for them, install it. Action: copy the install command. Proof: the Isolde Brackwater example, chiefly the round 1 FIX findings in review.md and how each was applied. Constraints: PRODUCT.md brand commitments (no real person's data, author as a one-line credit, no em or en dashes, no claims, 390 and 1440 px, dark mode, reduced motion, 4.5:1).

Chosen direction: the page is a code review of a job application. Memorable moment: the "7 Android and iOS engineers" line struck out in rose, the true line added in mint beneath, with the reviewer's FIX comment anchored to it and a blame gutter naming the fact that decides it.

Decision round: run unattended inside a subagent; assigned direction built without a decision page. Unresolved: none.

## Direction contract

THESIS: A job application reviewed like code. Claims are diff lines, each blamed to a fact id; the reviewer's FIX comments sit on the lines they caught. Refuses the tool-page default: headline, subcopy, button and three feature cards; also refuses the dark terminal with a neon accent.

OWN-WORLD: Cool violet-grey review paper (#f2f1f7) with ink #1c1a35; one indigo (#3b33a6) owns the left gutter rail that carries the navigation, and the ink of every blame column and fact id. Colour is law: rose only for what may not be written, mint only for what traces and ships, amber only for partial and QUALIFY FIRST.
