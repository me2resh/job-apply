Job applications, true in every line.

An add-on for Claude Code, Codex, Cursor and GitHub Copilot. It writes each CV and cover letter from your own fact bank, then has a separate reviewer attack them before you send.

Facts first, writing second

Most tailored CVs are either generic or stretched to fit the ad. Job Apply keeps the facts apart from the writing. The first run builds your fact bank by interview: your CV, LinkedIn export and reviews, then the numbers, the baselines, your part against the team's, and the evidence. After that, each application runs the same six steps, and nothing it writes says more than the bank can back.

  1. 1. Fetch the adThe page, then the hiring system's public JSON when the careers page blocks scripts, then an archived copy, then it asks you to paste it.In the example the careers page returned 403, so it read the public JSON.
  2. 2. GateYour own filters: pay floor, location and office days, right to work, industries you will not work for, seniority, must-haves, and a scale check. You see APPLY, QUALIFY FIRST or SKIP before a word is written.APPLY. Another role in her tracker was a SKIP: its core product sits in an industry she excluded.
  3. 3. MapEach criterion in the ad against your fact ids, marked strong, partial or gap. Gaps are told to you plainly and never papered over.Four strong, three partial, one gap.
  4. 4. WriteA CV to a fixed, ATS-safe skeleton and a 250 to 350 word letter, in your voice, using the ad's words where they are honestly true.A two-page CV and a one-page letter.
  5. 5. Check and reviewA script fails the documents on dashes, banned phrases, star counts and untraced numbers. Then a separate reviewer returns SHIP or FIX with line-level findings. Up to two rounds.FIX on both documents in round 1, eleven findings. SHIP in round 2.
  6. 6. RenderATS-safe PDFs with generic filenames, a folder per application, a tracker row, and a reminder to read it aloud and rewrite one sentence yourself. It never sends anything.Isolde-Brackwater-CV.pdf and Isolde-Brackwater-Cover-Letter.pdf.

Everything lives in one folder you choose, as plain markdown and YAML. Nothing leaves your machine except the job ad fetches.

Four things you ask it

Set up

Set up job apply.

Your fact bank, profile and voice file, built by interview. It reads your documents first and only asks what they leave out.

Apply

Apply for this: https://...

Gate verdict, criteria mapped to facts, a tailored CV and letter, reviewer verdicts, PDFs, form answers and a tracker row.

Reply

Reply to this recruiter: ...

A recruiter reply, referral ask or cold note. Short, one ask, and reviewed like everything else.

Update

Update my CV facts.

A new or corrected fact with a dated change log line, and a list of sent applications that used the old one.

The reviewer said FIX

The reviewer is a separate agent. It gets the ad, the fact bank and the voice file, and nothing the writer was thinking. On the example's first drafts it caught two real inflation errors. These are its findings, lightly trimmed, and what shipped instead.

1. Inflation, on the ad's first essential criterion

Draft

...with four years leading a team of 7 Android and iOS engineers

Reviewer
FIX

The fact bank says 5 mobile engineers, 1 backend engineer and 1 QA engineer, and she started with 3 in Apr 2022. So this is wrong twice: the team was not 7 for four years, and it is not 7 mobile engineers.

Shipped

A team of 7 reports to me, including 5 Android and iOS engineers.

2. Inflation: a cause the dates do not allow

Draft

which made weekly releases cheap

Why

Weekly releases started in Jan 2023 and the build cut was Feb 2024, so the build work cannot have made weekly releases possible.

Shipped

Sponsored the Android CI work that cut build time from 38 to 14 minutes, Feb 2024.

3. AI tells and voice

Draft

The team chose to keep two native apps, and I can explain why.

Why

No first person in CV bullets, and "I can explain why" teases the reader instead of stating a fact.

Shipped

Built a Kotlin Multiplatform proof of concept for shared pricing logic, Jun 2024. Not shipped: the team chose to keep two native apps.

Draft

Full right to work in the UK, no sponsorship needed

Why

A factual claim about her status that the bank did not hold. If it is wrong, it ends the process.

Then

She confirmed it, it went into the fact bank with a dated change log line, and only then stayed on the CV.

Install it in your agent

Pick your agent. It needs Python 3 (standard library only) and Chrome, Chromium, Edge or Brave for the PDFs.

One line, as a plugin. The skill then answers to /job-apply and adds the job-apply-reviewer agent.

/plugin install job-apply --marketplace me2resh/job-apply

Older versions: /plugin marketplace add me2resh/job-apply, then /plugin install job-apply@job-apply. From a shell: claude plugin install job-apply --marketplace me2resh/job-apply.

Codex reads skills from ~/.codex/skills. The installer copies the folder there.

git clone https://github.com/me2resh/job-apply
cd job-apply
./install.sh codex

Without the plugin agent, the reviewer runs as a fresh context with references/reviewer.md as its brief.

Cursor uses project rules. Copy the rule file into your project.

git clone https://github.com/me2resh/job-apply
mkdir -p .cursor/rules
cp job-apply/.cursor/rules/job-apply.mdc .cursor/rules/

Copilot reads repository instructions. Copy the instructions file into your project.

git clone https://github.com/me2resh/job-apply
mkdir -p .github
cp job-apply/.github/copilot-instructions.md .github/

If your project already has copilot-instructions.md, append the text instead of replacing it.

Any agent that reads a folder with a SKILL.md can use it.

git clone https://github.com/me2resh/job-apply
cd job-apply
./install.sh /path/to/your/agent/skills

For agents with a single instructions file, add AGENTS.md to it and keep skills/job-apply/ readable by the agent.

Then ask the way you would ask a friend who reads CVs for a living.

  • Set up job apply.
  • Should I apply for this? https://...
  • Tailor my CV and write a cover letter for this ad.
  • Reply to this recruiter: ...

Optional: pdftotext or pip install pypdf turns on the PDF text-layer checks.

Eight things it will not do

When two rules pull apart: honesty, then anti-cringe, then voice, then reviewer findings, then the ad.

  • Claim what the bank cannot back.Every line traces to your fact bank. A missing fact is asked for or left out.
  • Round up.Durations round down, headcounts are exact, and a single report is never made plural.
  • Call influence management.Influence is never written as line management, and a proof of concept is never production experience.
  • Stretch a recent skill.A skill you picked up recently is not stretched by the length of your whole career.
  • Write before the gate.The verdict comes first, on filters you set. A SKIP stops the run unless you override it, and the override is logged.
  • Sound like a machine.No dashes, no AI-tell phrases, no flattery about the company, no telling readers what they already know.
  • Review its own work.The reviewer is a separate agent or a fresh context, with its own brief.
  • Send anything.You do, after reading it aloud and rewriting at least one sentence in your own words.
